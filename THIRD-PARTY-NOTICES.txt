FFmpeg / FFprobe

  ffmpeg.exe: build 20181217-f22fcd4 (Zeranoe static build), from the npm package @ffmpeg-installer/win32-x64 4.1.0
  ffprobe.exe: from the npm package @ffprobe-installer/win32-x64 5.1.0 (gyan.dev build)
